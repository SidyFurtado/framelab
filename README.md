# Framelab

Painel para o Adobe Premiere Pro: https://framelabbr.pages.dev

Este repositório guarda só o que precisa ser público:

- **Release `engines-ffmpeg-9.0.2`**: o FFmpeg em LGPL-3.0 que o Framelab
  usa, com o código-fonte exato e a configuração de cada build.
- **Release `engines-2026.10`**: os motores que o Framelab baixa (FFmpeg,
  whisper.cpp, yt-dlp e os do próprio Framelab).
- **`tools/ffmpeg/build-mac.sh`**: o script que compila o FFmpeg do macOS.
- **Ramo `gh-pages`**: o endereço antigo do site, que leva ao novo.

O código do Framelab não é público. Suporte: https://wa.me/5584994172242
